About this project

This project is a web application built with Flask to help users understand and solve the FTRLP algorithm. It provides a user-friendly interface to visualize and interact with the problem.


What is the FTRLP problem

FTRLP stands for "Fault Tolerant Regenerator Location Problem". Imagine a network of nodes, where each node wants to connect with the others. However, there's a limitation: the signal from each node can only travel a certain distance.

To overcome this, Signal Regenerators can be used. These devices help extend the signal range by boosting the signal when it passes through the node that has the regenerator.

For example, without any regenerators, it's impossible for all nodes to connect with each other. But if you place regenerators at nodes [1, 2, 3, 4], then the entire network becomes fully connected.


What does FTRLP Algorithm do?

The FTRLP algorithm determines which nodes should be equipped with regenerators so that the network remains connected — even in the case of potential link failures. It aims to minimize the number of regenerators needed to maintain fault-tolerant connectivity.
