About this project

This project is a web aplication created on Flask to help users solve and understand the FTRLP Algorithm, by giving them a web application interface to help them solve/understand this problem.


What is the FTRLP problem

FTRLP stands for "Fault Tolerant Regenerator Location Problem", now imagine a network of nodes and each node wants to be able to connect with each other but there is a restriction of the distance that the signal of the node can reach.

But it can be used a Signal Regenerator to regenerate the signal so the node that has it can make the signals of other nodes reach further if they send it to this node.

I this example the network with no regenerators makes impossible to no nodes to be able to connect with all each other, but if its used some regenerators in nodes [1,2,3,4] now the nodes can reach all each other.


What does FTRLP Algorithm do?

Now the FTRLP Algorithm will figure out wich nodes activate as regenerators taking into account that some links of the network may fail, trying to find the combination of least number regenerators that makes the network work.
